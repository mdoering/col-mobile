# Catalogue of Life Mobile

A native iPhone app for browsing the [Catalogue of Life](https://www.catalogueoflife.org), the most comprehensive and authoritative global index of species.

- **Search** scientific and vernacular names across 2.5M+ accepted species
- **Browse** the tree of life from kingdom down to subspecies
- **Bookmark** your favorite taxa and revisit recently viewed ones
- **Maps & images** of occurrence data via [GBIF](https://www.gbif.org), for current releases
- **Submit feedback** that becomes a public GitHub issue for the data curators
- **Switch releases** between Latest, Latest Base, and recent annual COL releases
